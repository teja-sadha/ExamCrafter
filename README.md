# 🎓 ExamCrafter

> **Create. Customize. Challenge.**

ExamCrafter is a modern online examination platform built using the MERN stack. It allows administrators to create and manage online exams, while students can participate in exams, submit answers, and view their performance and results.

---

## 🚀 Features

### 👨‍💼 Admin

- Admin authentication
- Admin dashboard
- Create exams
- Edit exams
- Delete exams
- Publish and manage exams
- Add multiple-choice questions
- Edit questions
- Delete questions
- Set correct answers and marks
- View student submissions
- View detailed student results

### 👨‍🎓 Student

- Student registration and login
- Student dashboard
- View available exams
- View exam details
- Attempt online exams
- Timed examinations
- Submit answers
- Automatic result calculation
- View score and percentage
- View correct, wrong and unanswered questions
- View previous examination results
